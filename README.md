# Название и цель
Проект `module01_environment` предназначен для настройки базового рабочего окружения лабораторной работы №2, организации структуры папок и управления версиями проекта.

## Состав файлов
В репозитории находятся следующие элементы:
- `notebooks/lr01_runtime_order_vital.ipynb` — основной рабочий файл Jupyter Notebook.
- `data/` — папка для хранения исходных данных проекта.
- `docs/` — папка с сопутствующей документацией.
- `version_log.md` — журнал изменений проекта.
- `security_check.md` — отчет о безопасности публикации.

## Как открыть
Инструкция для проверяющего:
1. Скачать и распаковать ZIP-архив с проектом (или клонировать репозиторий).
2. Открыть терминал в корневой папке проекта.
3. Запустить Jupyter Notebook с помощью команды: `jupyter notebook`.
4. В браузере открыть файл `notebooks/lr01_runtime_order_vital.ipynb`.

## Проверка
Чтобы понять, что всё работает правильно:
1. В интерфейсе Jupyter Notebook выберите верхнее меню **Cell** -> **Run All** (или **Kernel** -> **Restart & Run All**).
2. Убедитесь, что все ячейки кода выполняются последовательно и без ошибок (нет красных сообщений об ошибках).

## Ограничения
Что не проверяется или может сломаться:
- Проект тестировался только на Python 3.10+. На более старых версиях библиотеки могут работать некорректно.
- Если переместить или переименовать файлы внутри папки `data/`, пути в коде сломаются и notebook выдаст ошибку `FileNotFoundError`.
- Внешняя проверка GitHub-репозитория недоступна в офлайн-режиме.
